# Modules Forbidden Lands pour Foundry VTT

Modules maison pour le système **Forbidden Lands** (Foundry VTT v13–v14), en français.

| Module | Rôle | URL du manifeste (à coller dans Foundry) |
|---|---|---|
| **fl-temps** – Le Temps des Contrées | Calendrier, lune, fêtes, météo avec effets visuels et sons | `https://raw.githubusercontent.com/Dorian-HR/forbidden-lands-modules/main/fl-temps/module.json` |
| **fl-effets** | Animations (JB2A / Sequencer) | `https://raw.githubusercontent.com/Dorian-HR/forbidden-lands-modules/main/fl-effets/module.json` |
| **fl-lieux** – Ambiances des lieux | Sons d'ambiance des lieux selon l'heure, la météo et la saison ; tavernes ; musiques de combat | `https://raw.githubusercontent.com/Dorian-HR/forbidden-lands-modules/main/fl-lieux/module.json` |
| **fl-actions** – Barre d'actions | Barre d'actions du token sélectionné | `https://raw.githubusercontent.com/Dorian-HR/forbidden-lands-modules/main/fl-actions/module.json` |
| **fl-combat** – Combat automatisé | Actions lentes/rapides, défense, dégâts, armure, soins | `https://raw.githubusercontent.com/Dorian-HR/forbidden-lands-modules/main/fl-combat/module.json` |

## Installer
Dans Foundry : **Modules complémentaires › Installer un module**, coller l'URL du manifeste en bas de la fenêtre, puis **Installer**.

## Mettre à jour
Dans Foundry : **Modules complémentaires › Mettre à jour**.

Les sons de fl-lieux viennent de Freesound et OpenGameArt, sous licence CC0 (voir `fl-lieux/CREDITS.md`).
